# Font projektu

Aplikace používá `Stardos_Stencil/StardosStencil-Regular.ttf`. Je přiložena také tučná varianta a licence `Stardos_Stencil/OFL.txt`. Font pochází z [Google Fonts – Stardos Stencil](https://github.com/google/fonts/tree/main/ofl/stardosstencil) a je vydán pod SIL Open Font License 1.1.

Před výrobním použitím ověřit vykreslení používaných potrubních kódů a geometrii můstků.
